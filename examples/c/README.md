# C 灰度图像算法实验

本目录是一份可在 PC 编译运行的 C99 教学程序。输入图像由程序固定生成，含透视形状的亮道路、亮度渐变、阴影、局部反光和可复现的孤立噪点；算法只读单通道 GRAY8，不做 RGB/HSV 等彩色处理。代码不调用任何控制算法。

## 编译与运行

Windows 安装 GCC/MinGW 后，在本目录运行：

~~~powershell
gcc -std=c99 -O2 -Wall -Wextra -Wpedantic image_lab.c -lm -o image_lab.exe
.\image_lab.exe generated
~~~

脚本会在 `generated/` 写入 19 张 PGM（灰度/掩码/边缘/扫描/IPM）结果，并打印当前输入的阈值、差比和样本、中线边界样本、缓冲区公式和访问次数相关信息。PGM 是 Netpbm 灰度格式，可用常见图像查看器或网页实验工具读取。

## 代码索引

| 函数 | 本章主题 | 看输出时观察什么 |
|---|---|---|
| `make_synthetic_frame` | 灰度数组与合成输入 | 路面和背景不是固定常数；阴影/反光会改变局部直方图 |
| `threshold_fixed` | 固定阈值 | 高于 T 的路面置白；低于 T 的背景置黑 |
| `otsu_threshold` | Otsu | 256 桶灰度直方图；最大类间方差对应候选阈值 |
| `intermeans_threshold` | 迭代双均值 | 用两类均值中点反复更新阈值，类别为空时停止 |
| `threshold_per_row` / `threshold_local_mean` | 逐行与局部阈值 | 光照变化下局部结果与全图阈值差别 |
| `difference_ratio_q7` | 灰度差比和 | 两值差异归一化到约 0–128，除数加 1 防止零除 |
| `median_3x3` | 中值滤波 | 孤立噪点被邻域中值替换，边缘附近也可能变化 |
| `morphology_open` / `morphology_close` | 开闭运算 | 小点/小洞修复与细边损失 |
| `canny_simple` | 简化 Canny | 高斯平滑、Sobel、非极大值抑制、双阈值连接 |
| `sobel` / `sobel_threshold` | Sobel 梯度 | 分别看 Gx、Gy 和幅值；阈值后会留下两侧边缘 |
| `scan_each_row` | 中间行向两边扫 | 每行独立，找亮路面到暗背景的边界跳变 |
| `scan_center_inherited` | 中线继承 | 上一行有效中点给下一行作搜索起点，丢线时保留 valid=0 |
| `scan_longest_column` | 双最长白列 | 先由底部连续白列长度找左右种子与有效扫描范围 |
| `trace_8_neighbor` | 八邻域 | 在 Sobel 边缘掩码上按方向顺序走，带访问图和最大步数 |
| `homography_from_quad` / `warp_ipm` | 逆透视 | 四对点求 3×3 单应矩阵，再逆向映射到鸟瞰图 |

函数参数使用固定行列，数组下标一律是 `image[y][x]`。白色前景极性统一为 255，黑色背景为 0。示例输入宽 80、高 48 是为了快速观察和模拟，不是实验室摄像头推荐分辨率。

## 先看 3×3 数字练习

输入：

~~~text
 20  20  20
 20 210 210
 20 210 210
~~~

若 T=100 且亮路面为白色前景，二值结果为：

~~~text
  0   0   0
  0 255 255
  0 255 255
~~~

差比和对 (210,20)：

~~~text
abs(210-20) × 128 / (210+20+1) = 105
~~~

对 (62,60) 约为 2。阈值是用来区分邻点跳变的参数；要用固定帧/相机数据标定，不能把示例数字直接复制上板。

## 目标板移植边界

本程序只负责处理已捕获的一帧灰度数据。真实总钻风相机的初始化、帧完成标志、DMA/缓冲区和像素尺寸须接入实验室驱动；驱动未提供，所以程序没有声称能直接编译成某块板的固件。

循环扫描整帧需要约 H×W 次像素访问；3×3 Sobel 每个有效像素做两次邻域卷积；Otsu 需先扫一遍建立 256 项直方图，再扫 255 个候选阈值。代码为了并列展示步骤保留多个全尺寸缓冲，MCU 上应复用静态缓冲/行缓存并实测峰值 RAM 与耗时。这里没有任何虚构的 MCU 帧率或精度。
